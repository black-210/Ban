## 🛡️ Reporting a Vulnerability

The CodeMentor team takes the security of developer tools and systems code seriously. Because CodeMentor inspects C, C++, and Rust code locally and suggests memory fixes, preventing any code execution vulnerabilities within the extension itself is a primary priority.

### Reporting Guidelines
If you discover a security vulnerability or exploit vector within CodeMentor:
1. **Do not disclose the issue publicly** on GitHub issues or forums.
2. Send an email to `security@codementor.dev` with:
   - Description of the vulnerability.
   - Steps to reproduce or sample C/C++/Rust snippet triggering the issue.
   - Potential impact and affected platforms.
3. We will acknowledge receipt within 48 hours and coordinate a coordinated disclosure timeline.

## 🔏 Privacy and Code Isolation
- CodeMentor is **100% offline**.
- It does **not** transmit any code, filenames, or symbols to remote servers.
- It does **not** execute user code automatically.
